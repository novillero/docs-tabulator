# Журнал изменений

## v.1.0 jan2025

Первая версия DocsTabulator: 

1. Скрипт работает через интерфейс командной строки.
2. Скрипт принимает текстовый файл, номера редактируемых строк и количество пробелов в отступе.
3. Скрипт возвращает обновленный текстовый файл с проставленными отступами.
4. В скрипте отсутствует проверка корректности введённых пользователем данных.
