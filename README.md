# DocsTabulator

## Общее описание

Некоторые диалекты маркадуна содержат элементы разметки, которые требуют добавления отступов перед строками. При редактировании или переформатировании md-файлов с такой разметкой приходится проставлять отступы вручную. Если объём изменяемого текста большой, это превращается в трудоёмкую и продолжительную по времени процедуру.

DocsTabulator (DT) — это скрипт, который автоматизирует подобные операции. Он забирает md-файл, добавляет необходимое количество пробелов в начале определённых строк, сохранять изменения и возвращает отредактированный документ.

### Алгоритм работы

1. Пользователь передаёт DT нужный файл.
2. Пользователь определяет диапазон строк, которые нужно изменить и передаёт эти данные DT.
3. Пользователь определяет количество пробелов в начале строки и передаёт эти данные DT.
4. DT обрабатывает файл, добавляя нужное количество пробелов в нужные строки.
5. DT сохраняет внесённые изменения.
6. DT возвращает обновлённый файл пользователю.

### Технические требования

DocsTabulator написан на python и корректно работает в версиях Python 3.0.0 и выше. Проверьте, что на вашем устройстве установлен python нужной версии (команда `python --version`). При необходимости обновите или установите python через [официальный сайт](https://www.python.org/downloads/).
 
### Инструкция

DocsTabulator является простой консольной программой. Запуск программы, а также ввод всех данных осуществляются в командной строке. 

1. Скачайте файл `DT.py` себе на устройство.
2. Откройте командную строку, перейдите в папку с `DT.py` и выполните команду `python DT.py`.
3. Введите название md.файла вместе с расширением. Если `DT.py` и md-файл находятся в разных папках, не забудьте указать относительный или абсолютный путь до файла:

    ```
    C:\Users\parawriter>python DT.py
    Введите название файла:C:\Users\files\test.md
    ```

4. Введите номера строк файла, в которые нужно добавить отступы. Вы можете ввести как отдельные строки через запятую, так и диапазоны строк через дефис:
    
    ```
    Введите номера строк (отдельные строки через запятую, диапазоны строк через дефис):4, 8, 14-25, 34-49, 51, 68
    ```

5. Введите число пробелов отступа:

    ```
    Сколько пробелов добавить? Введите целое число:4
    Файл обновлён.
    ```

    DocsTabulator добавит перед указанными строками файла отступы длиной в количество указанных пробелов.
